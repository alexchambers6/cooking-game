# Cooking Game

## What this is
A simple cooking game for iPhone, built as a single web page (index.html) with plain HTML, CSS and JavaScript. No frameworks, no build tools, nothing to install.

## About me
I'm new to coding and learning as we go. Keep code simple and well commented. After each change, briefly explain in plain language what you did.

## How the game works
- A customer arrives and orders a dish.
- The player taps ingredients from a pantry (some are wrong, as distractors).
- Then the player taps cooking steps in the right order (e.g. Mix, then Cook).
- Correct: happy customer, player earns coins. Wrong: friendly message, try again.

## Version 1 scope
- One dish only: pancakes (flour, eggs, milk; steps: Mix, Cook).
- Designed for a phone screen held upright; big buttons easy to tap.
- Cheerful, colourful look. Emoji are fine for ingredients and customers.
